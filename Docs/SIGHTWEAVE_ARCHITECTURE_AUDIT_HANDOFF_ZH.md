# SightWeave / DARKWELL 架构审计交接

本文件汇总本轮证据与迁移合同。详细实验、失败记录、构建与性能原始口径见 `SIGHTWEAVE_ARCHITECTURE_AUDIT_20260905.md`；普通对象接入见 `OBJECT_MEMORY_INTEGRATION.md`。本轮检查点不是新的用户验收 stable。

## 1. 原架构的问题

旧 epoch 同时表示一次进出视野操作和一种被观察到的对象状态。不变对象反复观察，也会分配新记录、冻结新的向内 AA 边界，之后再用新记录的硬所有权切掉旧表面。几何、外观与当前真实对象绑定，历史重建可能读到玩家没见过的新网格或颜色。成熟实现集中在 Lab Actor，普通 Rememberable 组件却走另一套旧 Presenter。细、粗历史同时维护部分事实，而大量逐样本贡献诊断混进了实时热路径。

“仅仅是旧 cap 没退场”不能解释 02 房间：隐藏全部 cap 后，三条内部竖线仍在。“历史必须永远保留所有旧 record”也是旧实现约束，不是玩家知识合同。首次 Whole 交接空帧不能用材质预加载、GPU 遮挡、AA、源材质清空或单独提前初始化纹理解释；提前准备透明代理的完整渲染资源消除了固定回放中的两帧空白。

## 2. 选择的重构

保留经过验证的合法视野、策略确认与几何采样能力，重构状态生命周期、表现资源所有权和生产入口。没有引入新玩法框架、第三方依赖或引擎修改，也没有为了重写而替换所有网格算法。

生产入口现在是 `ADarkwellObjectMemoryScene`。Lab 派生它，只负责测试对象、运动、控制台和报告。普通 Actor 加两个组件即可接入同一条路径。捕获是玩家观察到的状态；视野会话是对该状态继续观察；纹理、代理、封口是可重建缓存。

## 3. 删除和保留

删除了不变对象每次重入必建新捕获、每会话重新分配 Current 纹理、冗余 Current 世界图集上传，以及普通更新中无条件执行的精细贡献诊断。历史重建不再从当前真实 Actor 读取网格、相对姿态和颜色。完全无剩余表面或三维封口的终结记录可释放。

保留了 Current 局部网格、权威细历史、必要粗网格兼容数据、空间候选索引与独立空证据；它们没有被虚假地宣称全部统一。`Always` 和旧单快照能力保留给兼容调用者；空间记忆源显式跳过旧 Presenter。现代 Current API 可捕获超过 64 个真实新状态，旧 `BeginObservedLocation` 的容量约定保持兼容。

## 4. 新的事实与表现链

合法源及遮挡发布 → 每对象策略和世界厘米确认 → Current 合法观察 → 捕获几何/姿态/外观版本 → 细历史与反证 → 有效表面及封口 → 缓存回收/再进入。

相同静止姿态、几何、外观且无有效反证，可以延续原捕获和代理。不同版本分别保存。隐藏运动和隐藏外观变化不更新玩家知识。历史代理使用当时捕获的网格引用、相对变换、世界姿态、颜色与 UV 参数；后续重建不能读取隐藏的新状态。

具备捕获资格时提前准备历史纹理和透明代理，SpatialReady=0 明确禁止历史像素输出；合法封存后才绑定最终观察姿态、纹理和范围并显示。资源准备不生成 FineHistory，不提交历史图像，不适用于 Never 或未确认 Whole，也不会在每个运动步骤重复调整历史纹理尺寸。

黑色层尚未实施。以后应独立消费合法世界探索和显示上下文，不能从“Whole 已显示”反向扩展世界探索，也不能用最终屏幕像素生成记忆事实。当前分层允许这样接入；项目灰色材质仍是表现接口的一部分。

## 5. 02 房间接缝

基线真实回放证实三条内部竖向表面缺口，隐藏封口仍存在。独立解析长方体内部的自动化也失败：重复观察把同一静止物体拆成多个带独立冻结 AA 边界的状态，硬所有权裁剪后不能保证表面连续。

最终 `Room02_PreparedCaptureFinal` 在正常 D3D12/SM6 下采集 51 帧，六个最终快照各检查 896 个内部采样点，全部无缺口，编辑器正常退出。已查看原始完整历史、封口隐藏、再进入及离开图像：补全内部无旧分割线，未观察的一端仍受限制，合法外部切口保留。早期 `Room02_GameViewport` 的退出异常仍保留为失败证据。

## 6. 重复观察与增长

不变、未被反证的状态复用同一份捕获，继续获得新区域；已知区域不反复渐显。相同结果的覆盖、几何、纹理和 cap 不重复构建。完全被有效新内容替代的记录，在确认无剩余三维贡献后释放；部分未知旧内容继续保留。

重复分布历史的 1,800 帧测量中，121 个有效记录、细历史容量、纹理和代理数量保持稳定。真实新知识实验则通过六个合法观察到的物理姿态让记录增加，证明没有用丢弃新知识换取常数内存。当前没有磁盘分页；无限增加的未解决新知识仍会占用更多内存。

## 7. 隐藏变化与合法反证

StableID、内部真实 Transform、Moving 标记和对象销毁都不是“玩家已经知道旧位置为空”。旧捕获只有在合法覆盖、占据判断及既有反证规则下才更新。Superseded 不会转换为 VerifiedEmpty。重建和复用不能复活已经擦除的样本。

StationaryOnly 移动中继续 Live，但不记录路径；隐藏停止不产生终点知识。Never 不留下灰影。Whole 仍以默认 100 cm 世界长度确认，未确认时只有临时合法局部；确认后的整体权限不能越过真实墙体或探索地面及其它对象。

最终 1,800 帧分布历史中，记录/代理/cap 各 121、纹理 125、MID 361、细历史 44,966,912 字节始终不变；进程工作集仍增加约 184.7 MB，不能把资源计数稳定称为进程内存零增长。真实新知识让记录 2 → 7、纹理 6 → 11、细历史 3,809,280 → 11,329,536 字节。透明预备代理及纹理完整计入资源数。原始逐帧记录、游戏 DeltaTime、分阶段耗时和 Trace 均留在本机 Saved。

原生严格短测保持原门槛并通过。最终严格长测完成 54,000 活动帧及 600 静止帧：各分钟完整步骤 p95 8.143–8.539 ms，最高 37.998 ms，计入周期 GC，无连续 >33 ms、无 >100 ms、无合法 Live 丢失。提前准备资源有可测代价：此前长测完整步骤 p95 为 6.158–6.948 ms，不能只宣传空帧修复而忽略成本。最终分钟末记录/代理始终为 3，纹理 12、MID 36，工作集增长约 16.0 MB。它是十五分钟模拟时间，实际测试约 259 秒，不能称为十五分钟真实 GPU 运行。

## 9. 验证与仍待解决事项

正式 Editor 构建通过。准备代理之前回归为 118/118；最终运行时的完整回归为 117/118，唯一失败是旧断言把资源总数当成可见历史。改为验证零历史记录和零可见历史代理后，定向回归与长测 3/3 通过。因此选定的 118 项都有最终运行时上的通过结果；这不是重新跑了一次全绿的 118 项。独立期望包含解析几何内部覆盖、观察顺序、重复次数、30/60/120/144 Hz、大 DeltaTime、反证后重建不复活、隐藏几何/外观变化、源销毁与同身份替换。优化路径还逐样本对照原始完整计算。旧固定 record/NAME_None/代理分配数断言的迁移和失败原因均保留。

普通宿主测试使用无 Lab 名称依赖的瞬态世界、普通 Actor 和组件，涵盖六个策略对象、世界根网格、销毁、反证、Reset。真实回放另行检查墙体、Never、隐藏运动、外部封口及三次 Play/Stop。插件经关闭 PCH/Unity 的严格独立打包通过 Win64 Editor、Development 和 Shipping；最小宿主仅加载打包插件，不加载 DARKWELL 模块，策略/确认/代理/转换测试 21/21 全部通过。完整灰色表现仍是项目后端，不能把插件打包通过夸大为灰色渲染器已经独立插件化。

首次 Whole 空帧的旧失败证据全部保留。提前准备透明代理并完成父子姿态收敛后，最终 `Policies_PreparedCaptureFinal` 回放三次 Play/Stop、178 张原始图像中，24/24 张 Whole 离开帧通过独立像素检查，已查看首帧、边缘、隐藏停稳及墙体图像；该次编辑器正常退出。此结论针对已复现操作，不等于证明所有可能的首次渲染时序。

编辑器退出稳定性仍未解决：日志关闭后间歇 0xC0000005，晚附加调试器捕获到 Slate 文本布局释放堆栈；缺少引擎私有符号，尚未确定原始所有者。正常主窗口关闭路径也有复现，不能把数次正常退出称为根治。

因此：审计已形成可执行结论，主要重构已经落地；自动验证有明确通过项，也有明确失败项；用户人工验收待进行；退出异常和上述性能尖峰仍阻止将此分支标为新的稳定验收点。

## 10. 分支、迁移与最短人工复测

唯一推荐继续分支：`codex/darkwell-prop-memory-gameplay-lab`。最终交付 SHA 以交接回复及远端分支为准；没有创建另一条让两台机器使用不同实现的分支。原两条 stable 不作为本次实验目标。

没有 `.uasset`/`.umap` 迁移或引擎升级。本机实际引擎为 `D:\UE_5.8` 下 5.8.2 CL 56702186。普通集成显式配置 `bUseSpatialMemory`，注册场景，并保证“物体移动 → 合法视野发布 → UpdateMemory”调用顺序。当前项目表现合同是静态网格 primitive、直立 XY/yaw 几何、材质 slot 0 和灰层颜色/UV 参数；不宣称可快照任意材质图或原地修改后的资产网格。

最短复测：正式构建后打开 `/Game/Maps/L_SightWeaveGrayPolicyLab` 并 Play；在大厅 F 进入 `02 局部切块`，分次观察左/中/右，每次移开，再完整看过并移开，检查内部无旧竖线而外部合法切口仍在。随后去 `01` 确认 Whole 后快进快出，检查首次离开也立即有完整灰影；去 `03` 隐藏移动、停稳再观察；去 `05` 对照真实墙遮挡。最后 Reset、返回大厅、Stop、再次 Play。已知退出异常和性能尖峰应记录复现，不能让用户重复承担已知问题的发现工作。

本机 `Saved` 中的原图、日志、Trace、minidump 和插件包不提交 Git；脚本和本文数值随源码交付。其它电脑应重新采集，不能把本机生成物视为已随拉取获得。可运行 `Scripts/LaunchGrayPolicyLab.ps1` 打开人工复测地图。自动回放入口是 `Scripts/RunGrayMemoryAudit.ps1 -RunName <唯一名称> -Protocol Episodes` 或 `Contracts`；随后分别用 `AnalyzeGrayMemoryEpisodes.py` / `AnalyzeGrayWholeTransitions.py` 检查。性能入口是 `Scripts/RunGrayMemoryTransitions.ps1 -RunName <唯一名称>`。所有命令从仓库根目录运行，保留正常 D3D12/SM6 和项目画质。
