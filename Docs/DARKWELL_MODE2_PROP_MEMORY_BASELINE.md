## 冻结合同

### 权威状态

- 使用累计空间记忆 D/V/R。
- 已发现区域不会因为玩家转头立即消失。
- 已验证为空的区域不会恢复旧残影。
- 擦除和显露都由合法 SightWeave 空间覆盖驱动。
- 非法区域严格为零。
- StableID、快照、实际存在状态和 SightWeave 公共合同保持独立。
- 剖面、材质和抗锯齿均为表现层结果，不写回权威状态。

### 出现与消失

- PRESENT 物体按空间逐位置显露。
- 新区域约 `0.20` 秒局部进入。
- 离开当前覆盖的 Live 区域约 `0.18` 秒转为灰色记忆。
- 不允许整件突然弹出、Live 一闪即灰或接触一点便生成完整灰色快照。
- ABSENT 物体的旧残影由合法视野单调擦除。
- 已擦除空位在玩家转头后不得复活。
- 新位置或重新出现的真实物体在没有合法视野时不得泄漏。

### 几何与阴影

- 使用原始固定几何。
- 不通过缩放、WPO、重建网格、盒体替换或移动表面模拟显露。
- 原组件 Transform、Bounds、角点和全部原始顶点保持不变。
- PRESENT 但尚未直接显露的真实物体允许使用同一组原始组件投射隐藏阴影。
- ABSENT 后不得继续存在该物体阴影。
- 记忆代理和剖面不得增加重复阴影源。

### 双向剖面

- PRESENT 局部显露和 ABSENT 残影擦除使用相同的实心剖面边界规则。
- 统一剖面颜色为 sRGB `#343A40`。
- 当前材质路径为独立 `Opaque + Unlit + Two-Sided`，通过固定 Emissive 输出稳定中性深灰。
- 不读取或自动识别物品主体颜色，不做纹理平均色，不使用纯黑。
- 零覆盖、完整显露、完整擦除和 Mode 0/1 不显示剖面。
- 剖面只存在于合法的局部空间边界，不参与 StableID、快照、碰撞、占用或权威状态。

### 抗锯齿

- 使用已验收的 4×4 保守表现采样和双线性过滤。
- 抗锯齿只影响表现，不改变 D/V/R、合法覆盖或 `.20/.18` 时间合同。
- 在 1080p/1440p、正常 TSR、100% Screen Percentage 下保持稳定。
- 不允许通过扩大覆盖、提前显示、降低门限或写入非法区域隐藏锯齿。
